# Пример расчёта заказа (Магазин для животных)

## Исходные данные:
* **Название заказа:** Товары для кота
* **Имя заказчика:** Алексей
* **Позиция 1:** Упаковки корма
  * Количество: 3
  * Цена: 450.50 руб.
* **Позиция 2:** Игрушки
  * Количество: 2
  * Цена: 250.00 руб.
* **Стоимость доставки:** 300.00 руб.
* **Внесённая сумма:** 2500.00 руб.

## Ручной расчёт ожидаемых значений:
1. **Стоимость Позиции 1:** 3 * 450.50 = 1351.50 руб.
2. **Стоимость Позиции 2:** 2 * 250.00 = 500.00 руб.
3. **Стоимость товаров без доставки:** 1351.50 + 500.00 = 1851.50 руб.
4. **Общая сумма с доставкой:** 1851.50 + 300.00 = 2151.50 руб.
5. **Общее количество единиц:** 3 + 2 = 5 шт.
6. **Сдача:** 2500.00 - 2151.50 = 348.50 руб.
