# Результаты вычислений и прогнозов

## Прогнозы и результаты
* 2 + 3 * 4: прогноз 14, результат Python 14. Сначала умножение, затем сложение.
* (2 + 3) * 4: прогноз 20, результат Python 20. Скобки меняют порядок действий.
* 17 // 5: прогноз 3, результат Python 3. Целая часть от деления.
* 17 % 5: прогноз 2, результат Python 2. Остаток от деления.
* -7 // 2: прогноз -3, результат Python -4. Различие из-за округления вниз.

## Объяснение различия в -7 // 2
Оператор `//` в Python округляет результат в сторону отрицательной бесконечности (вниз). Деление `-7 / 2` равно `-3.5`, а ближайшее меньшее целое число — `-4`.
